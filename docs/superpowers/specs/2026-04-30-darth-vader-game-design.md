# ダースベーダーゲーム 設計仕様

## 概要

横スクロール・サバイバル型アクションゲーム。ダースベーダーが右から押し寄せる敵を倒し続け、スコアを競う。単一HTMLファイル（バニラJS + Canvas）で完結。

## 技術構成

- 実装：HTML5 Canvas + バニラJS（依存ライブラリなし）
- 配信：単一 `.html` ファイル
- フレームレート：60fps（requestAnimationFrame）
- 対応環境：モダンブラウザ（Chrome / Firefox / Safari）

## ゲーム状態

```
START → PLAYING → GAMEOVER
```

- **START**：タイトル画面。スペースキーで開始。
- **PLAYING**：ゲームプレイ中。
- **GAMEOVER**：HPが0になった時。スコア表示 ＋ リトライ。

## 画面・レイアウト

- キャンバスサイズ：800 × 500px
- 背景：ダーク宇宙空間。星が2レイヤーで右→左に流れる（視差スクロール）。
- ダースベーダー：左端（x=100）に固定。← → キーで上下移動。
- 敵：右端から出現し左方向へ移動。
- UI：右上にスコア・HP表示。

## キャラクター仕様

### ダースベーダー
- サイズ：60 × 80px
- 移動：← → で上下移動（速度 5px/frame）
- 攻撃：スペースキーで赤いライトセーバービームを発射（横方向・右へ）
  - ビームは画面右端まで達したら消える
  - 連射制限：0.3秒に1発
- HP：3（ダメージ時に白フラッシュ、1秒間の無敵時間）

### 敵：X翼
- サイズ：50 × 30px
- 右から左へ直線移動
- HPを1減らして消える（接触判定）

### 敵：ブラスター弾
- サイズ：10 × 6px（緑色）
- 30秒以降に出現。右から左に高速移動。
- 接触でHPを1減らす。

## 難易度スケーリング

| 経過時間 | 敵種類 | 出現間隔 | 速度 |
|----------|--------|----------|------|
| 0〜30秒  | X翼のみ | 2.0秒 | 2px/frame |
| 30〜60秒 | X翼 ＋ ブラスター弾 | 1.5秒 | 3px/frame |
| 60秒〜   | 両方 | 1.0秒 | 4px/frame |

## エフェクト

- **ライトセーバービーム**：赤、幅4px、shadowBlur でグロー
- **敵撃墜**：オレンジ・黄色のパーティクル10〜15個が放射状に飛び散る（0.5秒で消える）
- **ダメージ**：ベーダーが白く0.3秒フラッシュ

## スコア計算

- 生存時間：1秒 = 10点
- X翼撃墜：50点
- ブラスター弾撃墜：20点

## ビジュアルスタイル

- カラーパレット：黒・ダークネイビー・深紫を基調
- アクセント：赤（ライトセーバー）、緑（ブラスター）、オレンジ（爆発）
- グロー：`ctx.shadowBlur` を多用してネオン感を演出
- フォント：`'Courier New'` モノスペース系でSF感
